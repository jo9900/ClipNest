# Icon source

`AppIcon.png` is the original image generated with OpenAI's built-in imagegen tool
on September 15, 2026. It has a transparent canvas surrounding the teal tile.
`bash scripts/generate-icons.sh` uses macOS `sips` to produce the asset catalog sizes.

Prompt:

> Use case: logo-brand. Create one finished macOS app icon for a minimal clipboard
> history utility. A clean teal rounded-square tile containing two slightly offset
> stacked ivory paper sheets, the front sheet with two short teal horizontal lines.
> Geometric, balanced, quiet, spacious, friendly, crafted like an Apple desktop
> utility. Subtle depth at most; crisp edges and highly legible at 16 pixels.
> No letters, words, logo text, watermarks, pencil, scissors, border decoration, or
> extra objects. Icon centered and fills about 88 percent of a square 1024 by 1024
> canvas. Genuinely transparent background outside the rounded-square tile. This is
> the production icon asset, not a mockup, presentation board, screenshot or grid
> of alternatives.
