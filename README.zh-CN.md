# Copiary Clipboard

一个轻量的 macOS 剪贴板历史工具，Swift 原生开发，MIT 开源。

## 使用

- 支持 macOS 13 及更新版本，兼容 Intel 和 Apple 芯片。
- 首次启动点击 **开始记录**，开始记录文字和链接。
- 点击菜单栏图标，或按 **⌥⌘V**，打开屏幕居中的固定面板。
- 点击记录，或按上下方向键选择后回车；内容会复制到系统剪贴板，面板关闭并返回原应用，再按 **⌘V** 粘贴。
- **Esc** 或点击窗口外关闭；搜索框可筛选历史。
- 最多保存 20 条，重复内容移到最前，超过上限删除最旧的。
- **全部清空** 直接清空本地历史，保留当前系统剪贴板；右键一条记录可单独删除。
- 记录只显示内容和类型，不显示不断变化的时间。
- 设置中的 **登录时启动** 控制开机启动，**暂停记录** 暂停记录。
- 右键菜单栏图标可以打开设置、暂停或退出。

## 语言

界面跟随 macOS 语言，也可以在「系统设置 → 通用 → 语言与地区 → 应用程序」中单独设置。
提供英语、简体中文、繁体中文、日语、韩语、西班牙语、阿拉伯语、葡萄牙语（巴西及葡萄牙）、
马来语、越南语、印尼语、法语、德语、意大利语、俄语、印地语、泰语，共 18 个语言/地区版本。
阿拉伯语使用从右到左布局。剪贴内容始终保留原文。

## 数据与限制

历史会在重启后保留，只保存于本机沙盒内，不联网、不上传。
会跳过来源应用标记为敏感或临时的内容；无法识别没有标记的密码等敏感文本。
不需要辅助功能权限。部分系统版本需要在系统设置中允许读取其他应用的剪贴板。

首版支持文字和链接，不保留富文本样式，不保存图片或文件。单条文本最多 1 MiB，
约每 0.6 秒检查一次，过于快速的连续复制可能遗漏；暂停和退出期间不收录。

## 开发和发布

用 Xcode 16 或更新版本打开 `ClipNest.xcodeproj`，运行 ClipNest scheme。
没有第三方运行时依赖。完整构建、测试命令和目录说明见 [README](README.md)。

计划免费上架 Mac App Store，当前尚未发布。上架仍需开发者账号、分发签名和 Apple
审核，具体步骤见 [上架准备](docs/app-store.md)。
